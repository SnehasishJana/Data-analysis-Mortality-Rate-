# 📊 Data Analysis on Mortality Rate

## 📌 Project Description
This project analyzes a Mortality Rate dataset using Python.  
The objective is to clean the data, perform analysis, and visualize meaningful insights about mortality trends and influencing factors.

---

## 🛠 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- SciPy  

---

## 📊 Dataset
- File: `mortality.csv`  
- Contains mortality rate data used for analysis and visualization  

---

## ⚙️ Features
- Data preprocessing  
- Handling missing values  
- Data visualization  
- Insight generation  
- Basic predictive analysis

## 🚀 How to Run

1. Install Python  

2. Install required libraries:pip install numpy pandas matplotlib seaborn scipy
3. Run the project:python ProjectINT375.py
4. Make sure `mortality.csv` is in the same folder as the Python file
